Equity Conviction Monitor — Methodology

Quality mean-reversion terminal · S&P 500 + Russell 1000 + factor/regional ETFs

1 · Overview

A distinct terminal to the Crypto Conviction Monitor. Captures high-quality mean-reversion and factor-rotation opportunities in large-cap US equities and major factor/regional ETFs. Same v2 multiplicative philosophy — Conviction = 100 × Quality × Confirmation × RiskAdjustment — but with equity-native factors (fundamentals, multi-horizon RS vs SPY, short-interest, valuation). Updated nightly + 15-min intraday.

2 · Data

  • Polygon.io / FMP — price, volume, ADV, short interest, option skew (when available)
  • Tiingo / Yahoo — fundamentals (ROIC, FCF yield, margins, debt/EBITDA, earnings stability)
  • FRED / ETF.com — factor ETF constituents & factor exposure weights
  • Universe — S&P 500 + Russell 1000 constituents + ETFs (EWJ, EFA, VEU, IWD, QUAL, VLUE, MTUM, USMV, IWM, EEM, VWO, AAXJ, …)

3 · Conviction Model

Each eligible name gets one 0–100 score. The identical function runs in the terminal (JS) and the nightly builder (Python), tested byte-identical via tests/test_parity.py (parity gate + FROZEN_CONVICTION regression).

// v2 MULTIPLICATIVE (replaces v1 additive on 2026-08-04):
// forced by the crypto v1 ceiling collision — clamping momentum erased discrimination.

Q = Structural Quality  (log-mcap floor + fundamentals)
C = Market Confirmation   (soft tanh over rs_blend vs SPY/sector; NO hard clamp)
R = Risk Adjustment   (liquidity-fit × short-interest × valuation, 0.4–1.0)

conviction = clamp( 100 · Q · C · R , 0, 100 )

signal: STRONG ≥80 · BUY ≥70 · HOLD ≥55 · WATCH ≥40 · AVOID <40

Quality — Structural Quality

  • ROIC clamp(ROIC / 0.25) — 25% = excellent
  • FCF yield clamp(FCF yield / 0.08) — 8% = excellent
  • gross margin clamp(gross / 0.50)
  • balance sheet clamp(1 − debt/EBITDA / 3.0)
  • earnings stability 3-yr earnings-volatility inverse
  • mcap depth log-mcap floor; blue chips (depth≥0.90) get Q≥0.4 so a rich single metric never annihilates a quality leader.

Confirmation — Multi-horizon RS

rs_blend = 0.30·rs7d + 0.25·rs14d + 0.25·rs30d + 0.20·rs200d — relative to sector then SPY (so sector beta doesn't masquerade as alpha). Log-return based, vol-normalised. Mapped through a soft tanh(rs_blend/25) sigmoid — no clamp, so names inside a tier stay ranked by RS strength. A mean-reversion kicker lifts C when a high-ROIC leader sits ≥10% off its 52-wk high (unwinding = confirmation, not risk).

Risk Adjustment — the down-weight

This is where thin-float pumps and expensive momentum traps get multiplied down:

  • Liquidity fit — dollar ADV tiers (log scale): $1M/d≈0.25, $10M≈0.5, $100M≈0.75, $1B≈0.9, $10B+≈1.0. Floored at 0.25 so thin names aren't zeroed, never a blanket mega-cap grant.
  • Short interest — days-to-cover ≥3 starts a linear drag; 33d → full kill
  • Valuation z-score — forward P/E or EV/EBITDA vs 5-yr median; cheap lifts, rich dings
  • Perp/options overlay — RiskMultperp, currently 1.0 (no derivatives feed; flips on once short-interest + option-skew ingest is live).
Conjunctive gate (eligibility). A name is qualified only if it clears Liquidity (ADV ≥ 0.25% mc), Valuation (forward P/E ∈ [5, 40] or EV/EBITDA ∈ [4, 25]), and Regime (not a macro risk-off / LIQ TRAP) — simultaneously. The gate filters eligibility; the score ranks among eligible names.

4 · Portfolio Construction

Paper index of the top-10 eligible names by conviction, score-proportional weights, daily rebalanced. Performance attribution decomposes into Q / C / R contributions per name.

5 · Special Modules

Module A — Liquidity & Short-Interest (turnover band + days-to-cover)
Module B — Stability/ERA (24h stability of RS)
Module C — Fundamentals (the Quality composite)
Module D — Factor Exposure (Value / Quality / Momentum / Size / Low-Vol from ETF weights)
Module E — Mean-Reversion Overlay (RSI(14) troughs, Bollinger %B, 200d distance, 52w drawdown)

6 · Caveats

  • Free-tier limits. Polygon/FMP free tiers lack intraday order book and full fundamental history. Modules are scoped to real fields; anything un-sourced is marked unavailable.
  • Calibration. The z-score / threshold bands were set from representative mega-cap fixtures and single-asset ranges, not a calibrated S&P 500 universe. Retune against realised 12-mo realised vs conviction ranks before treating scores as investible.
  • Mean-reversion ≠ free money. A high-Quality / deep-drawdown / strong-RS-setup (the MSFT-style candidate) is a probability filter, not a guarantee.
  • Paper only. Research signal system, not investment advice.
  • Perps/options overlay is server-side. RiskMultperp needs a short-interest + options-fit feed (no cross-origin client call). The terminal reads the nightly perp_mult field so client and index stay consistent.
